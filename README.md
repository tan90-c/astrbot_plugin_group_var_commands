# 自定义函数指令 (astrbot_plugin_group_var_commands)

按会话（QQ 群 / 私聊）独立配置一套「变量分组 + 全局函数模块 + Python 指令脚本」，群成员或私聊对象发送指令即执行脚本并回复结果。全程 WebUI 可视化配置，保存即生效。

仅支持 QQ 官方机器人平台：qq_official、qq_official_webhook。

## 功能一览

1. 会话绑定：机器人收到过消息的群聊/私聊自动出现在首页列表中，一键绑定生成独立标签页（QQ 式左侧会话列表），无需手填任何 ID；每个会话一份独立配置
2. 会话跟随：标签页可通过「绑定会话」挂到某个主会话下——绑定后本标签页只读，变量分组/函数模块/指令全部实时跟随主会话；解绑即恢复原有内容（备注名与删除标签页始终可用）
3. 备注名：会话标签页头部可填备注名；左侧列表只显示备注名，详情页标题显示原始会话 ID
4. 自定义变量分组：多个命名分组，每组任意键值对（存服务器 IP/端口/后台账号密码等），支持 ↑↓ 排序、分组改名/删除
5. 全局函数模块：每个会话可定义多个 Python 模块（模块=一个 .py 文件，内含多个函数），指令脚本 `import 模块名` / `from 模块名 import 函数` 直接复用，消除重复代码
6. 自定义指令：无限多条；每条绑定一个 Python 脚本；支持多个附属指令名（别名）
7. 全自动保存：面板内任何修改即时写入配置并生效，无需重启

## 触发语法

群内/私聊直接发送（`/` 前缀可选，效果相同）：

```
状态                 ← cmd="状态", value=[]
状态 1区 2区          ← value=["1区","2区"]
s 1区                ← 别名 s 等同 状态
查二服玩家 12312      ← 模板别名 查{*}玩家：value=["二服","12312"]
```

1. 群聊 @机器人 的消息（`[At:xxx]` 组件前缀、回复引用标记）自动剥离后再匹配，发「查二服玩家」即可命中
2. 模板别名用花括号占位，花括号内任意内容都是通配（`查{*}玩家` 与 `查{服务器}玩家` 等价）；群成员直接发 `查二服玩家` 即触发，无需带花括号；多个占位按出现顺序各捕获 value 一个元素；占位内容不可为空
3. 主指令名同会话内唯一；触发词按固定文字最长优先匹配；别名撞主名走主名指令，别名互撞后创建者生效
4. 未绑定会话、未命中指令：完全静默，不回复不打扰

## 指令脚本

```python
from utils import fmt          # 可选：导入全局函数模块

def main(args, cmd, alias, value):
    g = args.get("主服", {})
    return f"{g.get('name')} ({fmt(g.get('ip',''), g.get('port',''))}) 运行中"
```

默认入参（`main()` 按名取用，用不到的不写）：

| 参数 | 类型 | 含义 |
| --- | --- | --- |
| `args` | dict | 全部变量分组：`{"分组名": {"键": 值, ...}}` |
| `cmd` | str | 主指令名 |
| `alias` | str | 命中的别名；主名触发时为空串 |
| `value` | list | 参数列表（模板捕获内容在前，尾部空格参数在后） |

输出规则：

1. 返回值转字符串直接作为回复：`str` 原样、`dict`/`list` 转 JSON、`None`/空不回复
2. 脚本内 `print` 的内容附在返回值前（分隔线隔开）
3. 脚本报错/超时静默无回复，仅记后端日志，不影响机器人运行
4. 回复格式可在首页切换：markdown 卡片 / 纯文本（强制 msg_type=0，PC 端 QQ 推荐）

## 安装

1. AstrBot WebUI「插件」→ 从仓库地址安装：`https://github.com/tan90-c/astrbot_plugin_group_var_commands`；或将本文件夹放入 `data/plugins/`
2. 重启/重载插件，要求 AstrBot >= 4.9.2、Python >= 3.10
3. 打开插件详情页的「控制面板」开始配置；机器人需已在目标群且收到过至少一条消息（或收到过你的私聊消息），才能在首页会话列表中被选中绑定

## 配置存储

1. 面板所有修改写入 `data/config/astrbot_plugin_group_var_commands_config.json`，结构为 `script_timeout / reply_format / groups.<会话umo>.{note, bind, modules, groups, commands}`（bind 非空=只读跟随该主会话）
2. 高级 JSON 区实时展示当前会话完整配置（自动与页面同步），粘贴新 JSON 可一键导入覆盖；「复制全部」从其他标签深拷贝变量分组+函数模块+指令；「绑定会话」把当前标签挂到所选主会话（只读跟随），按钮变「解绑会话」
3. 机器人见过的会话记录缓存于 `data/plugin_data/astrbot_plugin_group_var_commands/sessions.json`（仅用于面板展示选择）

## 安全须知

1. 指令脚本以 AstrBot 进程的完整权限运行（可读写文件、发网络请求），控制面板与 WebUI 账号务必只交给可信管理员
2. 变量分组里存放的服务器密码等仅保存在本地配置文件中，不会出现在群聊回复里——但脚本返回值会原样发出，写脚本时注意不要把敏感字段拼进回复
