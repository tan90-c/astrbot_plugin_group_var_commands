# 群变量指令 (astrbot_plugin_group_var_commands)

AstrBot 插件：按群号管理聚合分组变量，自定义指令绑定 Python 脚本执行。自带 WebUI 可视化控制面板，群内零管理指令。

## 安装

1. WebUI「扩展功能」从仓库地址安装 `https://github.com/tan90-c/astrbot_plugin_group_var_commands`，或将整个文件夹放入 `data/plugins/`。
2. 重启/重载插件。
3. 打开 WebUI 插件详情页 → 「控制面板」进行全部配置；保存即生效，无需重启。

要求 AstrBot >= 4.9.2（控制面板；核心功能 >= 3.4），Python >= 3.10。脚本在独立 Python 子进程中运行，无额外依赖。

## 控制面板

1. 群与全局：添加/删除群号（删除有确认弹窗）、脚本超时
2. 群超级管理员：当前群超管 QQ 名单（逗号分隔，仅本群生效）
3. 自定义变量分组：添加/改名/删除分组（均有确认弹窗）与每组内变量增删改（v1.5.0 起取消旧的 vars 卡片，全部走分组，保存时自动丢弃旧 vars）
4. 指令配置：创建/删除指令、附属指令名（别名）增删、执行权限下拉、Python 脚本编辑器（v1.6.0 起取消输出变量配置）
5. 高级 JSON：双向同步，可整段粘贴导入

## 指令别名（附属指令名，v1.5.0）

1. 每条指令可添加多个别名，群内发别名等同发主指令。
2. 主指令名在同群内唯一。
3. 别名与其他指令的主名重复 → 调用主名指令。
4. 别名与其他指令的别名重复 → 后创建的主指令生效。
5. 触发按最长匹配；脚本里 `cmd` 始终是主指令名，`alias` 是命中的别名（主名触发时为空）。

## 指令权限（v1.4.1）

每条指令可选四档执行权限：

| 级别 | 可选者 |
| --- | --- |
| 群成员（包含管理和群主） | 任何人（默认） |
| 群管理（包含群主） | 管理员/群主 |
| 群主 | 仅群主 |
| 超级管理员 | 仅本群【群超级管理员】名单中的人 |

1. 超级管理员按群配置（不跨群）：控制面板「群超级管理员（当前群）」卡片，逗号分隔多个 QQ 号。
2. 名单内的人在本群无条件通过所有权限档。
3. 群管理/群主两档依赖适配器查询成员身份：OneBot v11（aiocqhttp，NapCat/LLBot 等）通过 get_group_member_info 自动识别，结果缓存 60 秒；无法识别时会明确拒绝并提示，不会误放行。

v1.3.0 变化：删除了“入参绑定”——脚本不再需要声明来源，直接按名取用默认入参；面板删除操作全部改为页面内确认弹窗（修复 iframe 中 confirm 失效导致“删除无效”），变量表改为收割式重建（修复重复添加/删除出现幽灵 var1/var2 的问题）。

## 脚本默认入参

`main()` 形参按需取用，运行器按签名自动过滤（用不到的不写，多余的不传）：

| 参数 | 类型 | 含义 |
| --- | --- | --- |
| `args` | dict | 自定义变量分组全量：`{"分组名": {"变量名": 值, ...}, ...}` |
| `cmd` | str | 主指令名 |
| `alias` | str | 命中的别名；用主指令名触发时为空串 |
| `value` | str | 指令名后面的参数原文（如 `状态 1区` 中的 `1区`） |
| `sender_id` | str | 触发者 QQ 号 |
| `sender_name` | str | 触发者昵称 |
| `group_id` | str | 群号 |

脚本返回值直接作为回复：

1. `str` 原样发送；`dict`/`list` 转 JSON 字符串；`None` 或空字符串 → 不回复。
2. 脚本内 `print` 的内容会附在返回值前（分隔线隔开），便于调试。
3. 脚本报错/语法错/超时：默认无回复，仅记后端日志（指令名+错误摘要），机器人不崩溃不受影响。

## 触发方式

群成员在已配置的群内发送：

```
状态
/状态
状态 1区          ← cmd="状态"，value="1区"
s 1区             ← 别名触发：cmd="状态"，alias="s"，value="1区"
```

按指令名最长优先匹配；指令名不含空格；未配置的群/指令一律静默。

## 配置结构（WebUI 插件设置 JSON）

```json
{
  "script_timeout": 30,
  "groups": {
    "1122334455": {
      "aggregate": true,
      "super_admins": "12345678,87654321",
      "groups": {
        "Group1": { "ip": "192.168.1.10", "port": "25565", "name": "示例服务器" }
      },
      "commands": {
        "状态": {
          "script": "def main(args, cmd, value):\n    g = args.get(\"Group1\", {})\n    return f\"{g.get('name')} ({g.get('ip')}:{g.get('port')}) 运行中\"",
          "perm": "member",
          "aliases": ["s", "查询"]
        },
        "重启": {
          "script": "def main(cmd, value):\n    return \"已下发重启\"",
          "perm": "admin",
          "aliases": []
        }
      }
    }
  }
}
```

## Hello World 示例

```python
def main(cmd, value):
    return "Hello, " + (value or "World") + "!"
```

群成员发 `问候` → `Hello, World!`；发 `问候 AstrBot` → `Hello, AstrBot!`

## 注意事项

1. 脚本拥有与 AstrBot 进程相同的系统权限，控制面板/配置页仅交给可信管理员。
2. 旧配置里的 `inputs`、`outputs` 字段已废弃：保存时自动丢弃，不影响加载。
3. 聚合分组 `aggregate` 字段保留仅为兼容，现在恒为启用。
