# 群变量指令 (astrbot_plugin_group_var_commands)

AstrBot 插件：按群号管理聚合分组变量，自定义指令绑定 Python 脚本执行。自带 WebUI 可视化控制面板，群内零管理指令。

## 安装

1. WebUI「扩展功能」从仓库地址安装 `https://github.com/tan90-c/astrbot_plugin_group_var_commands`，或将整个文件夹放入 `data/plugins/`。
2. 重启/重载插件。
3. 打开 WebUI 插件详情页 → 「控制面板」进行全部配置；保存即生效，无需重启。

要求 AstrBot >= 4.9.2（控制面板；核心功能 >= 3.4），Python >= 3.10。脚本在独立 Python 子进程中运行，无额外依赖。

支持平台：aiocqhttp（OneBot v11，NapCat/LLBot 等）、qq_official（QQ 官方机器人）、qq_official_webhook。其他平台的群聊理论上也能触发，但未做适配验证；群管理/群主权限档仅在前三个平台可自动识别。

## 控制面板

1. 群与全局：**从会话列表绑定群**（下拉选择机器人已在的群，自动用会话来源 umo 作键，无需手填群号；手动输入仅作为折叠的高级选项）、脚本超时；删除操作均有确认弹窗
2. 自定义变量分组：添加/改名/删除分组（均有确认弹窗）与每组内变量增删改，变量表支持 ↑↓ 排序
3. 指令配置：创建/删除指令、别名（支持多个 `{*}` 模板）、执行权限三档（群成员/群管理/群主）、代码编辑器（高亮+行号+Tab缩进）
4. 高级 JSON：双向同步，可整段粘贴导入
5. v1.9.0 变更：新增会话绑定；**彻底取消超级管理员/QQ号白名单**（旧 super 档自动降为群主档，super_admins 字段保存时丢弃）

## 会话绑定（v1.9.0）

1. 机器人被拉进群并在该群收到过任意消息后，该群就会出现在面板「群会话」下拉里（含群名/平台/群号或openid）
2. 点「添加并绑定会话」即以会话来源 umo 为键创建配置，保存生效；跨平台不会串号
3. 存量配置的数字群号/openid 键仍兼容可用（ umo 键优先匹配）
4. QQ 官方机器人无法取到明文群号/QQ号（平台限制，只有 group_openid/member_openid）；要明文和 QQ 号白名单类玩法请用 OneBot v11（NapCat/LLBot）接入

## 指令别名（附属指令名，模板 v1.8.0）

1. 每条指令可添加多个别名，群内发别名等同发主指令。
2. 别名支持 `{*}` 占位符模板，可用多个，每个按顺序捕获为 `value` 的一个元素：如 `查{*}玩{*}家{*}` 收“查二服玩张三服家456” → `value=["二服", "三服", "456"]`；旧的 `{value}` 写法自动视为单个 `{*}`。
3. 占位内容不可为空；模板后可接空格参数，并入 `value` 尾部。
4. 主指令名在同群内唯一。
5. 别名与其他指令的主名重复 → 调用主名指令。
6. 别名与其他指令的别名重复 → 后创建的主指令生效。
7. 匹配按固定文字长度最长优先，同长时非模板优先；脚本里 `cmd` 始终是主指令名，`alias` 是命中的触发词（模板已规范化为 `{*}` 写法）。

## 指令权限（v1.4.1）

每条指令可选四档执行权限：

| 级别 | 可选者 |
| --- | --- |
| 群成员（包含管理和群主） | 任何人（默认） |
| 群管理（包含群主） | 管理员/群主 |
| 群主 | 仅群主 |

1. 群管理/群主两档依赖适配器查询成员身份：OneBot v11（aiocqhttp，NapCat/LLBot 等）通过 get_group_member_info 自动识别；QQ 官方机器人通过事件里的 member_roles 识别；结果缓存 60 秒；无法识别时明确拒绝，不会误放行。
2. v1.9.0 起不再有超级管理员档/QQ号白名单；旧配置里的 `super` 档保存时自动降为 `owner`，`super_admins` 字段自动丢弃。

v1.3.0 变化：删除了“入参绑定”——脚本不再需要声明来源，直接按名取用默认入参；面板删除操作全部改为页面内确认弹窗（修复 iframe 中 confirm 失效导致“删除无效”），变量表改为收割式重建（修复重复添加/删除出现幽灵 var1/var2 的问题）。

## 脚本默认入参

`main()` 形参按需取用，运行器按签名自动过滤（用不到的不写，多余的不传）：

| 参数 | 类型 | 含义 |
| --- | --- | --- |
| `args` | dict | 自定义变量分组全量：`{"分组名": {"变量名": 值, ...}, ...}` |
| `cmd` | str | 主指令名 |
| `alias` | str | 命中的别名；用主指令名触发时为空串 |
| `value` | list | 参数列表：普通触发按空格拆分；模板按 `{*}` 出现顺序各捕获一个，尾部空格参数追加在后 |
| `sender_id` | str | 触发者 QQ 号 |
| `sender_name` | str | 触发者昵称 |
| `group_id` | str | 群号 |

脚本返回值直接作为回复：

1. `str` 原样发送；`dict`/`list` 转 JSON 字符串；`None` 或空字符串 → 不回复。
2. 脚本内 `print` 的内容会附在返回值前（分隔线隔开），便于调试。
3. 脚本报错/语法错/超时：默认无回复，仅记后端日志（指令名+错误摘要），机器人不崩溃不受影响。

## 触发方式

群成员在已配置的群内发送：

```
状态
/状态
状态 1区 2区         ← cmd="状态"，value=["1区", "2区"]
s 1区                ← 别名触发：cmd="状态"，alias="s"，value=["1区"]
查二服玩家 12312     ← 模板别名 查{*}玩家：cmd="玩家"，value=["二服", "12312"]
查二服玩张三服家456   ← 模板别名 查{*}玩{*}家{*}：value=["二服", "三服", "456"]
```

按指令名最长优先匹配；指令名不含空格；未配置的群/指令一律静默。

## 配置结构（WebUI 插件设置 JSON）

```json
{
  "script_timeout": 30,
  "groups": {
    "aiocqhttp:Group_Message:1122334455": {
      "aggregate": true,
      "groups": {
        "Group1": { "ip": "192.168.1.10", "port": "25565", "name": "示例服务器" }
      },
      "commands": {
        "状态": {
          "script": "def main(args, cmd, value):\n    g = args.get(\"Group1\", {})\n    return f\"{g.get('name')} ({g.get('ip')}:{g.get('port')}) 运行中\"",
          "perm": "member",
          "aliases": ["s", "查询", "查{*}玩家"]
        },
        "重启": {
          "script": "def main(cmd, value):\n    return \"已下发重启: \" + (value[0] if value else \"默认\")",
          "perm": "admin",
          "aliases": []
        }
      }
    }
  }
}
```

## Hello World 示例

```python
def main(cmd, value):
    return "Hello, " + (value[0] if value else "World") + "!"
```

群成员发 `问候` → `Hello, World!`；发 `问候 AstrBot` → `Hello, AstrBot!`

## 注意事项

1. 脚本拥有与 AstrBot 进程相同的系统权限，控制面板/配置页仅交给可信管理员。
2. 旧配置里的 `inputs`、`outputs` 字段已废弃：保存时自动丢弃，不影响加载。
3. 聚合分组 `aggregate` 字段保留仅为兼容，现在恒为启用。
